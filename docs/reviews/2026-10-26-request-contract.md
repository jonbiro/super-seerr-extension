# Seerr request contract review — October 26, 2026

Version **3.5.261**, branch `master`. This pass compared request creation, failed-request handling, standard-quality seasons and specials against Seerr's stable **v3.5.1** server code. It also checked single-title and bulk feedback, safe title links, keyboard focus and Firefox content-script scope. The overall extension review goal remains active.

## Fixed findings

- **False success without a new request:** Seerr returns HTTP 202 with a message when no selected seasons remain requestable. The extension previously accepted any successful HTTP reply and could record a nonexistent request. Receipts now require a positive request ID, matching TMDB identity/type/quality, a valid status and confirmed selected TV seasons. Malformed or contradictory receipts explain that the user should check Seerr; no automatic second write occurs, and no confirmed recent action is recorded.
- **Duplicate failed-request actions:** failed requests reserve titles/seasons until handled through Seerr's existing retry workflow. The old Try Again action submitted a new request. It now opens the exact Seerr title, with URL validation and opener isolation. TV season review continues to offer genuinely new seasons; Plex remains independent.
- **Silently omitted specials:** Seerr removes season zero when special episodes are disabled. Review and pre-write validation now fetch the active server's current public setting. Disabled or unconfirmed specials cannot authorize a mixed request. A failed setting read leaves ordinary seasons usable, and existing specials availability remains visible. Site/key/generation guards cover the additional read.
- **Misreported partial or failed confirmations:** a concurrent request can cause Seerr to create only some selected seasons, and a newly created request can already carry a failed, declined or completed status. Confirmed outcomes retain their receipt/history but display persistent review warnings. Bulk feedback lists them separately from ordinary successes. A malformed worker reply cannot bypass the client or bulk checks.
- **Missing Firefox helper:** the new browser regression found that exporting the shared validator only on the content global did not supply the season picker's window dependency. The module and client now use the same content-window export convention as the other shared UI modules. All nine discovery script groups and dynamic Seerr registration load it before consumers.

Season review identifies the server and provides an accessible link to its title, preserving configured subpaths. Invalid URLs produce no link. The link participates in the focus loop; review warnings stay available until dismissed and do not auto-close the flyout.
