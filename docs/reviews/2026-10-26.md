# Extension review — October 26, 2026

Version: **3.5.254**. Reviewed the worker, permissions and messaging, settings and migrations, multi-site isolation, shared public ratings, matching and requests, season/bulk flows, filters and presets, all nine discovery adapters, Plex and tracker accounts, diagnostics/history, and build/release scripts. This is a review with targeted fixes and regression coverage, not proof that every path is defect-free.

## Fixed findings

| Finding | Correction and evidence |
| --- | --- |
| A page-supplied TMDB ID could cause status-cache results for one title to appear on another after matching rejected that ID. | Include title/year evidence in the status key; keep raw detail/history reads shared. Regressions cover both lookup orders and same-name remakes. |
| Plex diagnostics accepted proxy HTML or unrelated JSON as a healthy connection. | Require a positive account ID and select a readable account label. Worker and popup regressions reject invalid responses. |
| Host keyboard shortcuts could cancel flyout button activation and Tab navigation. | Stop bubbling keyboard events from the flyout. A browser regression exercises Enter, Space, Tab, and Escape with cancelling host shortcuts. |
| Several flyout labels had insufficient contrast on brand gradients or light/dark panels. | Adjust label/gradient colors and test rendered request, watchlist, playback, tab, and library-badge text in normal/hover states across all nine themes. These checks cover the specified labels, not full accessibility conformance. |
| Two transitive development dependencies had known advisories. | Patch `source-map-js` to 1.2.2 and `undici` to 7.30.1. Neither is bundled into the extension runtime. See the [source-map-js advisory](https://github.com/advisories/GHSA-68fv-2mgg-jv7q) and [undici advisory](https://github.com/advisories/GHSA-4qv8-2p9j-2685). |

## Verification

- `npm test`: **1,786 passed**, including a full rerun after the dependency patches.
- `npm run test:browser`: **272 passed** in Chromium. The two contrast tests were also rerun after the dependency patches.
- `npm run test:firefox`: **passed on Firefox 157.0.1**, including the real 3.5.2 upgrade, twenty synthetic discovery pages, and two saved Seerr sites.
- `npm run check`, `git diff --check`, and `npm audit --audit-level=high`: passed; audit reports **0 vulnerabilities**.
- `make build`: produced Chrome and Firefox 3.5.254 packages. Generated source, documentation, and manifest versions were compared with the checkout.
- `web-ext@10.6.0 lint`: **0 errors, 2 warnings** for dynamic HTML templates in the filter and bulk-review UI. Inspection found internally generated counts/configuration and escaped title text in those templates; no unsanitized title insertion was identified.

The browser suites use local HTTP fixtures and disposable profiles. They cover real extension loading, upgrades, worker lifecycle, permissions, layout and interactions; they do not establish authenticated production-service acceptance.

## Live-site results and remaining limits

Read-only Chromium checks used a disposable profile and no service credentials. No real requests, watchlist writes, or consent choices were made.

The broad initial run used work-in-progress source labeled 3.5.253. After the theme changes and build, the six TMDB/Letterboxd/RT cases were rerun at 3.5.254: five passed and RT TV remained blocked. Other adapter extraction code was unchanged.

- Passed: TMDB movie/TV and Spanish movie; Letterboxd movie on follow-up runs; RT movie; Metacritic movie; Filmweb movie/TV.
- Blocked: IMDb, Trakt, Simkl, and JustWatch returned HTTP 403/challenge pages. The extension correctly produced no false requestable title on these pages, but their live media integration remains unverified.
- RT TV extracted the correct title/year, but its consent dialog intercepted interaction. Retesting requires a user-selected privacy choice.
- The initial Letterboxd run failed Escape-to-close while host content covered the tab. An instrumented retest and two harness retests passed, including the final 3.5.254 check. The cause remains unconfirmed; the initial failure is preserved.
- Real authenticated Seerr/Plex actions, cross-device settings sync, provider OAuth consent with registered Trakt/Simkl app IDs, signing, publishing, and store approval remain separate checks.
