Super Seerr

Configure your Seerr server connection. Save a server URL for ratings-only mode; add an API key to enable requests.

Super Seerr needs permission to run on your Seerr server before it can add ratings, sorting and bulk actions to those pages. Your settings are saved.
The URL of your Seerr server (including http/https)
Get your API key from Seerr Settings → General → API Key
Sign in at app.plex.tv, open DevTools Console (F12), run localStorage.getItem('myPlexAccessToken'), and paste the value.
Seerr page enhancements Click Save Settings to apply changes. Testing a connection does not save it.
Troubleshooting
Off by default. Turn this on only while reproducing a problem: the log can include media titles and Seerr responses, so review it before sharing. Ratings you have already seen are kept so revisiting Seerr does not look them up again. They do not expire; clear them to force a fresh lookup. Clearing takes effect in open Seerr tabs.

How to get your API Key

  1. Open your Seerr web interface
  2. Go to Settings → General
  3. Scroll down to find the API Key section
  4. Copy the API key and paste it above

Features

  • 🍅 RT ratings overlay on Seerr pages (no API key needed)
  • ✅ Request buttons on IMDB, Rotten Tomatoes, and TMDb pages
  • ✅ Request buttons on Letterboxd, Metacritic, Trakt, and Filmweb
  • 🔍 Automatic media matching using title, year, and TMDb ID
  • 📊 Visual feedback for request status and monitoring
  • 📺 Support for both movies and TV series
  • ⭐ Plex Watchlist button on Seerr detail pages and in the flyout (needs a Plex token)
