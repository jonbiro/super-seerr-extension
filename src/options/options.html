Troubleshooting
Off by default. Turn this on only while reproducing a problem: the log can include media titles and Seerr responses, so review it before sharing. Cached ratings appear immediately and refresh in the background as they age. Verified public scores are shared; Seerr-specific ratings and title indexes stay separate. Clear cached ratings for all sites and public sources to force a fresh lookup. Clearing takes effect in open Seerr tabs.

How to get your API Key

  1. Open your Seerr web interface
  2. Go to Settings → General
  3. Scroll down to find the API Key section
  4. Copy the API key and paste it above

Features

  • 🍅 RT ratings overlay on Seerr pages (no API key needed)
  • ✅ Request buttons on IMDB, Rotten Tomatoes, and TMDb pages
  • ✅ Request buttons on Letterboxd, Metacritic, Trakt, Filmweb, Simkl, and JustWatch
  • 🔍 Automatic media matching using title, year, and TMDb ID
  • 📊 Visual feedback for request status and monitoring
  • 📺 Support for both movies and TV series
  • ⭐ Plex Watchlist button on Seerr detail pages and in the flyout (needs a Plex token)
